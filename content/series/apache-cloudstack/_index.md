Apache CloudStack is an open-source infrastructure-as-a-service platform: it orchestrates pools of compute, network and storage so users can provision virtual machines, networks and storage on demand, across one or more hypervisors, from a single control plane. It is an Apache top-level project and is deployed both as private clouds and by commercial providers.

This page is the index of our hands-on CloudStack series. Each post is grounded in the official Apache CloudStack documentation and a real lab environment, and they are written to be read in order — but every post stands on its own if you only need one topic.

For the structured reading path, the domain breakdown and the lab setup, start with the [Learning Path & Roadmap](/post/cloud/acs/cloudstack-learning-path/). If you are new to the platform, [Part 1: Architecture & Core Concepts](/post/cloud/acs/cloudstack-01-architecture/) is the place to begin.
